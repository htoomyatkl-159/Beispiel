# Beispiel data sources

The development catalog is a 40-track metadata export prepared from the user's existing Spotify Tracks Dataset work. It contains song titles, artist text, genres, popularity, duration, and audio features. The original source project and dataset are preserved outside this repository and are not modified by the application.

The application does not ship copyrighted audio, stream songs, or download music. Decorative artwork is generated SVG interface branding; it is not album artwork. A production catalog or live trends integration must use an approved provider, comply with its terms, and document attribution and rate limits before it is enabled.

There is currently no live trending-music provider configured. The website must not describe the 40-song development catalog as millions of songs or as live trends.
